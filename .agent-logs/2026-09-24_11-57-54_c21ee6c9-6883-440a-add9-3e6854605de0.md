## Root cause (your console errors)

Two issues stacked:

1. **`getSnapshot` not cached** — `getStudioLibrarySnapshot()` called `readLibraryFromStorage()` on every read, which always returned a **new array reference**. React’s `useSyncExternalStore` treats that as “store changed” → re-render → read again → **infinite loop**.

2. **`subscribeHydrated` called `onChange()` on subscribe** — that pattern can also force extra update cycles. It’s removed; the library grid no longer needs a separate “hydrated” flag.

## Fixes applied

- **`src/lib/studio-library-client.ts`** — cache by raw `localStorage` string; reuse a stable `EMPTY_SNAPSHOT`; update cache on write; invalidate on cross-tab `storage` events.
- **`src/hooks/use-studio-library.ts`** — single `useSyncExternalStore`; `append` returns `boolean` (save success).
- **`LibraryPageClient`** — dropped redundant `hydrated` loading branch.
- **`ImageComposer`** — if save fails (quota / blocked storage), show a clear warning instead of “Saved to Library”.
- **Removed `LibraryPageBody.tsx`** — dynamic `ssr: false` wrapper was an extra layer; page imports `LibraryPageClient` directly.

`npm run test`, `lint`, and `build` all pass.
