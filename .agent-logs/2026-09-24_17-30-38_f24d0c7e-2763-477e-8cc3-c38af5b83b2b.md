### Highest-risk areas (now explicit in the plan)

1. **Preset handoff** — Effect cards must keep [`composerHrefForPreset`](src/data/effect-presets.ts) → `/image?preset=…`. Visual simplification (e.g. removing flip) is fine; **changing the link or resolver is not**.

2. **Video deep links** — Copying Image’s `searchParams` logic verbatim is unsafe: video models use [`getVideoComposerModelById`](src/lib/studio-recipe.ts), not Soul’s image models. The plan now requires a dedicated `resolveVideoComposerPageState` + tests for cross-mode ids (e.g. `soul-v2-standard` on `/video`).

3. **Two different “remix” concepts** — URL `?prompt=` overrides preset fields via [`resolveComposerPageState`](src/lib/composer-initial-values.ts). URL `?remix={id}` is the **library** flow in [`ImageComposer`](src/components/ImageComposer.tsx). The Create box must **never** emit `remix=`. The plan corrected that wording.

4. **Hardcoded dark colors** — [`StudioShell`](src/components/StudioShell.tsx) (`#0c0c12`), [`StudioBackdrop`](src/components/StudioBackdrop.tsx), [`globals.css`](src/app/globals.css) (`#0e0e14`), and `hover:bg-white/5` will look broken on a light theme if tokens alone change. The plan requires a grep pass in the same pass as token updates.

5. **Duplicate prompt UX** — Putting the Create box on Image/Video **and** keeping the composer forms risks desync. Default is now: **Create box on home (+ Effects optional)**; composers stay the single source of truth on `/image` and `/video`.

6. **Empty home grid** — Filtering by Image/Video/Library must show **workflow tiles**, not only effect presets, so pills do not yield an empty grid.

### New plan sections

- **Must not change (behavioral contract)** — URLs, storage, API calls, masonry logic, existing 12 `src/lib/*.test.ts` files  
- **Risk register and mitigations** — 8 concrete failure modes  
- **Regression smoke checklist** — 9 manual steps + full `npm test`  
- **Expanded edge cases** — alerts/shimmer on light bg, API key hydration layout shift, zero-match `/effects?q=`, masonry footer height, media autoplay rules  
- New todo: **regression-audit** (grep + checklist)

### What stays intentionally unchanged

- All `/api/**` routes and generation handlers inside composers  
- `localStorage` library format and `sessionStorage` API key format  
- [`imageComposerHrefFromRecipe`](src/lib/composer-remix-url.ts) and library remix links (still image-only today)
