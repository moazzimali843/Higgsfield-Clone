Forgot-password flow is wired through Supabase, matching your existing sign-in UI and auth callback.

### Flow
1. **Sign in** → “Forgot password?” → `/login/forgot-password`
2. User submits email → `resetPasswordForEmail` with redirect to `/auth/callback?next=/login/reset-password`
3. Email link → callback exchanges the code for a session → `/login/reset-password`
4. User sets a new password → `updateUser({ password })` → redirected to `/library`

### What was added
- `ForgotPasswordPageClient` + `/login/forgot-password`
- `ResetPasswordPageClient` + `/login/reset-password` (handles missing/expired links)
- Link on the sign-in form
- Auth shell layout for all `/login/*` routes (same centered layout as sign-in)
- Auth callback `next` is validated via `normalizeStudioReturnPath`, with an explicit allow for `/login/reset-password`
- Note in `docs/SUPABASE.md`
