Rechecked the plan against the repo and [docs/DEPLOY.md](docs/DEPLOY.md). The plan file is rewritten in **spec-driven** form: problem statement, functional requirements, API contracts, constraints, edge cases, acceptance criteria.

### Main conflict found

[docs/DEPLOY.md](docs/DEPLOY.md) and [README.md](README.md) require a **logged-out** path: Demo generate → **Library shows the result**. A strict “auth required to save” design would break that reviewer flow and today’s [`ImageComposer`](src/components/ImageComposer.tsx) / [`VideoComposer`](src/components/VideoComposer.tsx) behavior (`append` → localStorage).

### Non-regression strategy (added to plan)

**Dual-mode library layer:**

| Session | Persistence |
|--------|-------------|
| Guest | Unchanged `localStorage` (`higgsfield-studio-library-v1`, cap 48) |
| Signed in + verified | Postgres via `/api/library*` + RLS |

On login: import localStorage → DB (dedupe by `output_url`), then clear the local key. **No global auth wall** on studio pages or `/api/demo/*` / `/api/higgsfield/*`.

### Other edge cases now explicit in the plan

- **Showcase IDs** (`showcase-*`) stay static; never written to DB; detail page must still resolve them from [`preview-media`](src/lib/preview-media.ts).
- **`excludeOutputUrls`** if library fetch is slow — hydrate or include optimistic append.
- **POST library fails after a successful generate** — show result, `savedToLibrary: false`, optional retry.
- **Middleware** — session refresh only; narrow matcher; no redirects on public routes.
- **Missing Supabase env** — `npm run build` still passes; guests keep working.
- **Import** — invalid JSON rows, non-UUID ids, aspect_ratio CHECK failures, 48-item cap.
- **Multi-tab** — `storage` events (guest) + refetch on focus (authed).
- **Higgsfield keys** — still sessionStorage only (unchanged BFF).

### What stays untouched

Demo/Higgsfield API contracts, browser polling, reference upload limits, [`studio-library.ts`](src/lib/studio-library.ts) pure helpers and existing unit tests, sidebar/API-key UX.
